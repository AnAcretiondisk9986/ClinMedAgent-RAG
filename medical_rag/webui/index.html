本地医学教材库

索引保存在项目下的 .medical_rag/library.sqlite3，PDF 不会被上传。左侧选择教材即可预览、翻页、查看识别文本与处理状态。

处理流程都在做什么？
  1. 导入即检测：带文字层的 PDF 跳过 OCR，直接从文字层解析入库（几秒）；图片型 PDF 才走下面的 OCR 流程。
  2. OCR 文字识别：用 rapidocr + PP-OCRv6 逐页识别图片型 PDF，输出文本框坐标。
  3. 版面/表格页检测：PP-DocLayout 扫描全书，找出含表格的页面。
  4. 表格结构还原：裁出表格区域，还原为带 rowspan 的 HTML 表格。
  5. OCR 定向纠错：修正“聘→腭、挠→桡、於→于”等在教材语境下无歧义的错字。
  6. 版面结构化：xy-cut 分栏、段落重建、标题层级、页码校准（原书页 = PDF 页 − 偏移）。
  7. 建立检索索引：把结构化 Markdown 写入 SQLite，供 pi / Codex / CLI 按页码引用。
